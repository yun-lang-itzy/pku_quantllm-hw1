# 绩效指标与假设

以下公式为待核验起始笔记，需要来源与手算验证。先固定净值、费用、采样和外部现金流定义，再计算指标。

## 简单收益与复利

无外部出入金、净值为正时，单期简单收益 `r_t = E_t / E_(t-1) - 1`。累计收益为 `E_T / E_0 - 1`，也等于 `prod(1 + r_t) - 1`。有外部现金流时必须另定收益口径，不能直接套用净值比。

初始净值是计算的一部分；不要遗漏第一段收益或回撤。价格收益与扣费后的账户收益不同。

## 年化收益

等间隔采样、`n` 个有效收益区间、每年 `A` 个该类区间时，可用 `(E_T / E_0) ** (A / n) - 1` 描述几何年化收益。`n` 是收益区间数，不是价格观测点数。

日频教学可暂取 `A = 252`，但它不是所有市场的常数；不规则时长应按实际时间约定。短样本年化容易产生夸大的数字，需同时展示样本长度和累计收益。

## 回撤

定义历史高点 `H_t = max(E_0, ..., E_t)`。回撤率 `D_t = E_t / H_t - 1` 非正。若最大回撤报告为正的损失幅度，则 `MDD = -min(D_t)`；报告必须写明符号约定。

回撤依赖采样频率；日终净值看不到盘中风险。净值归零或变负时，常用收益与年化公式需要专门处理。

## Sharpe

令 `x_t = r_t - rf_t`，其中无风险收益 `rf_t` 与收益频率、单位一致。常见样本估计为 `mean(x) / std(x, ddof=1)`。在相应独立性/相关性假设下，常用年化近似乘以 `sqrt(A)`。

收益存在自相关、样本很短、波动接近零或分布异常时，这个数值的解释会受影响；标准差为零或样本不足时返回缺失并说明原因，不输出无穷大的“好指标”。

## 最低报告组合

累计收益、样本长度、最大回撤、成本、交易次数/换手和清楚定义的基准；若使用年化与 Sharpe，附频率、无风险利率和计算假设。胜率本身无法说明盈亏规模或尾部损失。
