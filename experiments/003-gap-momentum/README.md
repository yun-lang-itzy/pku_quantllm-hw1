# 跳空动量因子挖掘：首轮候选与实验约束

状态：**候选设计完成，历史数据与市场口径待确认；已执行挖掘轮数 0，未产生绩效结果。**

用户要求：每轮 10–20 个因子、最多 4 轮。本轮预登记 16 个候选；后续每轮最多 16 个，整个任务不超过 64 个候选。后续不凑满轮数：若无稳定增量或数据不足，提前停止。下述为原创待检验假设，不是已发现的有效因子。

## 输入待确认

- 市场与标的池、历史数据路径/可访问数据源、起止日期、时区、分钟线或日线。
- 期货需要实际合约、交易日与 session 日历、日盘/夜盘划分、历史主力选择规则；股票需要公司行动与可交易池口径。
- 分钟输入至少应含：symbol、exchange、datetime、trading_day、session_id、open、high、low、close、volume。数据时间戳是 bar 起点还是终点必须明确。
- 已有 SIMNOW 的几十条 tick 日志不足以挖掘。不得用合成数据、换月价差、除权或数据断档充当有效跳空。

以下先预登记 session 级定义；最终市场/频率确认后、查看效果前冻结执行配置。只有日线数据时，F11–F16 无法计算，不能以当日最高/最低价替代开盘窗口。

## 统一符号和时序

每个样本对应同一实际标的的一次目标 session 开盘。`O` 为该开盘价，`C−/H−/L−` 为上一个指定完整 session 的收盘/最高/最低，`g=O/C−−1`，`s=sign(g)`。价格非正、缺失或分母为零则不计算。

`ATR20−` 为之前 20 个完整 session 真波幅均值；`a=ATR20−/C−`；`σ20−` 为之前 20 个完整 session 收盘收益样本标准差；`z=g/a`。所有滚动统计不含当前 session。期货日盘开盘与夜盘开盘不混在同一基准序列中；另明确上一段收盘取哪个 session。

`m5=C−/C−6−1`，`m20=C−/C−21−1`；历史 gap 的 mean/std 也仅用过去样本。`I(条件)` 为条件为真时 1，否则 0。所有因子方向预设为数值越高、未来收益越高；反向显著须单独报告，不能事后翻符号当作动量成功。

F01–F10 在开盘价确认后可计算，不能假设自己还能按同一开盘价成交。F11–F16 在开盘后前 5 分钟全部结束后可计算。分钟数据初步采用：开盘组在首分钟结束后计算、下一根 bar 开盘模拟执行；确认组前 5 根分钟 bar 结束后计算、下一根 bar 开盘模拟执行。使用各自入场时点计算后续收益，不把信号形成窗口收益计入预测目标。实际成交可行性与成本另行验证。

## 首轮：16 个候选

| ID | 因子与公式 | 假设/用途 |
| --- | --- | --- |
| F01 | 原始开盘跳空：`g` | 跳空方向是否延续；基准 |
| F02 | ATR 归一化跳空：`z` | 跳空相对历史波幅的大小 |
| F03 | 波动率归一化跳空：`g/σ20−` | 用收益波动尺度替代价格波幅 |
| F04 | 异常跳空：`(g−mean(g过去20次))/std(g过去20次)` | 新信息相对惯常开盘偏移 |
| F05 | 区间外跳空：`[max(O−H−,0)−max(L−−O,0)]/ATR20−` | 跨过前一 session 区间的突破 |
| F06 | 顺短趋势跳空：`z × I(g×m5>0)` | 5-session 动量方向确认 |
| F07 | 顺中趋势跳空：`z × I(g×m20>0)` | 20-session 动量方向确认 |
| F08 | 同向跳空持续性：`z × mean(I(g×g过去5次>0))` | 最近多次同方向信息累积 |
| F09 | 压缩后跳空：`z × clip(ATR20−/ATR5−,0,3)` | 短期波幅压缩后出现跳空 |
| F10 | 大幅跳空：`z × I(abs(z)>=0.5)` | 过滤相对波幅较小的开盘变化 |
| F11 | 首5分钟延续：`r5/a × I(g×r5>0)`，`r5=P5/O−1` | 跳空之后价格进一步顺向运动 |
| F12 | 未回补跳空：`z × I(未触及C−)` | 向上 gap 要求 `L5>C−`；向下要求 `H5<C−` |
| F13 | 剩余缺口：`z × clip(s×(P5−C−)/abs(O−C−),0,1)` | 到第5分钟尚保留多少缺口；g=0 时为0 |
| F14 | 量能确认：`z × clip(V5/mean(过去20个同类session的V5),0,3)` | 跳空是否有开盘量能支持 |
| F15 | 开盘区间强度：`z × clip(0.5+s×(P5−(H5+L5)/2)/(H5−L5),0,1)` | 向上跳空收在区间高位，向下收在低位；区间为0时缺失 |
| F16 | VWAP 同向确认：`z × I(s×(P5−VWAP5)>0)` | 第5分钟价格是否位于开盘成交均价的趋势一侧 |

`P5/H5/L5/V5` 为前5分钟末价/最高/最低/成交量。VWAP5 需要真实成交额/成交量并按合约乘数换算，或逐笔价格量计算；只有 OHLCV 时 F16 标记不可用，不用典型价假冒真实 VWAP。零成交窗口缺失。不同原始数据可用性须在执行前解决，至少满足10个可计算候选才启动一轮。

F02/F03、F06/F07 等存在预期冗余，列入本轮是比较机制口径，不代表16个独立发现。与 gap 的单调变换不给予“新信息”结论。

## 评估与轮次控制

1. 数据审计：重复、缺失、时间戳、异常价格、session 边界、合约换月/公司行动；保存输入文件哈希与排除原因。具体市场未确认前不下载任意替代市场数据。
2. 按时间冻结开发/验证/最终留出区间，先暂拟60%/20%/20%；准确日期、最小样本量、主预测周期、交易成本在首轮计算前登记。按最大标签持有期剔除跨边界样本。
3. 主预测周期暂拟入场后30分钟，辅助60分钟及 session 末尾；均不得跨休市/合约切换，最终口径由数据决定。全部周期和因子尝试进入台账。
4. 跨标的同一时点样本足够时计算横截面 RankIC；单标的则按时间计算相关和分组收益，不能冒充横截面 IC。报告实际样本数、覆盖率、有效非零比例、分组单调性、不同时间段及标的表现。
5. 以不含未来信息的基准（原始 gap、过去动量）比较增量；相关性去重在开发集上做，拟以 `abs(Spearman)>0.85` 聚类，各簇保留解释清晰的代表。按交易日分块评估不确定性，多重检验同时记录全部尝试，不只展示最好结果。
6. 费用和滑点敏感性、换手、回撤需要可执行持仓/撮合口径；在股票卖空/T+1或期货合约乘数等规则未确认前，不把因子多空分组价差称为可实现收益。
7. 第1轮：16个基础/条件因子。第2轮：仅围绕有样本外支持的机制扩展10–16个候选；第3轮：10–16个跨窗口/跨session机制；第4轮：如确有必要，再预登记10–16个新候选。每轮先冻结候选再评估。稳健性复核不冒充新增因子轮次。
8. 达到4轮、连续两轮无去重后的样本外增量、数据质量不合格或样本不足时停止。最终留出只在选择与规则冻结后查看一次；验证集反复使用须明确承认是适应性开发，不称为独立测试。
