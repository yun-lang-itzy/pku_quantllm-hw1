# 单次价格触发下单

入口：[trade_demo.py](trade_demo.py)。复用已有原生 TD/MD 登录；默认 **dry-run，只打印意图**。

## 行为

1. TD 登录 → 结算确认 → 查询指定合约 → MD 登录/订阅。
2. 最新价 **严格大于**阈值时，按卖一价买入开仓 1 手限价单；第一次收到的有效行情已满足条件，也会触发，不要求先从下方向上穿越。
3. 每次运行最多触发一次，发送失败也不重报；重启会重置这一限制。
4. 发送后 10 秒仍未终结则申请撤单；撤单请求成功不代表撤单成功，继续等待回报。15 秒未确认则报状态未知，需在柜台核对。
5. Ctrl+C 或时长到期时也尝试撤销本次未完成委托，再释放接口；断网、撤单拒绝或强制终止不能保证撤销。已经成交的仓位不自动平仓。

仅支持既有 SIMNOW 9999 / 182.254.243.31:30001、30011 配置。校验合约交易状态、最小变动价位和 1 手限制；报价需在涨跌停范围、有卖一量、交易日匹配且更新时间距上海本地时间不超过 5 秒。旧快照不会触发；主机时钟需准确。

## 运行

在项目根目录，先验证意图（下列阈值 1 仅是工程测试值，不是策略建议）：

```bash
.venv/bin/python experiments/002-ctp-demo/trade_demo.py --symbol m2701 --threshold 1 --duration 20
```

实际仿真委托需先确认合约、阈值，再手动添加 `--send-order`。`--symbol`、`--threshold` 必填，不自动选取交易标的；默认无限运行，Ctrl+C 退出。账号复用被 Git 忽略的 `config.local.json`。

日志顺序：`[TD]` 结算/合约确认 → `[INTENT]` 触发 → `[DRY-RUN]` 或 `[INSERT]` → `[ORDER]` / `[TRADE]` / `[CANCEL]`。不会保存或输出密码。`[UNRESOLVED]` 表示必须核对柜台委托状态。
