# 实验目录

已有 [实践 002：底层 CTP 最小 Demo](002-ctp-demo/README.md)，实现 TD 认证登录、MD 登录订阅和行情打印；已完成原生编译与离线测试，真实 SIMNOW 登录/行情仍待可用 TCP 网络验证。详见 [实验报告](002-ctp-demo/report.md)。

基础学习任务与 [最小回测器](../wiki/projects/minimal-backtester.md) 仍按 [学习路线](../wiki/roadmap.md) 独立验收，不能由 Demo 的完成情况替代。

每个实验独立目录，例如 `001-data-basics/`，存放代码、固定输入或生成脚本、运行说明、依赖版本与 `report.md`。报告使用 [实验模板](../templates/experiment.md)。

合成输入应足够小，便于手算。真实数据记录出处、版本、获取方式和内容哈希；大文件不直接塞进仓库。`outputs/` 和 `cache/` 默认忽略，关键验收结果保留在报告中。

未执行的任务写“未执行”。程序能运行、账目正确、样本外证据充分是不同层次的判断，应分别记录。

验证完成的观察再沉淀到 Wiki，关联来源、概念与问题；如将报告作为来源，原样归档固定版本并登记哈希。
